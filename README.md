# Excel Financial Performance Dashboard

## Project Overview

This project analyzes a synthetic coffee shop financial dataset using Microsoft Excel. Financial information from bank transactions, payroll records, credit card transactions, and sales data was consolidated into a monthly financial summary and executive dashboard.

The dashboard was designed to help management monitor revenue, expenses, and profitability across the reporting period.

## Tools and Skills Used

- Microsoft Excel
- SUMIFS
- XLOOKUP
- Date Functions
- Data Cleaning
- Financial Reporting
- Data Visualization

## Dashboard Features

- Key Performance Indicator cards
- Monthly Revenue Trend
- Annual Expense Comparison for 2022 and 2023
- Monthly Net Profit Trend
- Monthly Financial Summary
- Consolidated reporting from multiple financial sources

## Dataset

The project uses the "Coffee Shop Financial Dataset" from Kaggle.

This synthetic dataset covers the period from January 2022 to December 2023.

## Key Insights

- Revenue experienced several noticeable fluctuations throughout the reporting period, including declines from January to March in both 2022 and 2023, as well as periods of growth from June to September 2022 and June to October 2023.
- Payroll represented the company's largest expense throughout the reporting period, followed by Credit Card Expense and other operating expenses.
- Revenue growth did not always translate into profitability. Net profit fluctuated between positive and negative values, with losses occurring in April 2022, June 2022, March 2023, June 2023, and September 2023.
- A comparison of annual expenses between 2022 and 2023 showed no significant changes in the company's overall cost structure.
- The executive dashboard provides a consolidated view of key financial metrics, enabling management to monitor revenue, expenses, and profitability over time.
